# 功能、操作与实现范围

本项目是浏览器运行的中文第一人称 3D 体素沙盒，参考 Minecraft 的采集、合成、建造和探索体验。它采用独立代码、程序生成的像素纹理与合成音效，不是官方客户端，也不是任何一个原版版本的逐项复刻。下面按实际代码说明可玩内容与边界。

当前数据表包含 39 种非空气方块、76 种非空气物品（包含方块物品）、27 个合成配方和 10 种烧炼转换。部分材料只可通过创造物品栏或命令获取，不能将物品目录等同于完整生存获取链。

## 世界与画面

- 按种子确定性生成地形；同一种子生成相同的基础地形，玩家改动另行保存。
- 水平方向按需生成、加载和卸载区块，区块为 16 × 16，垂直高度为 96 格。
- 草原、森林、沙漠、雪山、沙滩和海洋；地表有树木、草、花、仙人掌和西瓜。
- 地下包含洞穴、煤矿、铁矿、金矿、钻石矿和基岩。
- 原创像素方块纹理，方块顶面、底面与侧面可分别取样；可见面网格、邻接遮蔽与地下明暗变化。
- 天空渐变、方形太阳与月亮、星空、移动的方块云；20 分钟昼夜循环。
- 晴天和雨天，水下颜色与雾效；雨天可用命令切换。
- 半透明水面、玻璃、冰、树叶与交叉平面植物。
- 第一人称手部与持物动画、选中轮廓、挖掘裂纹、破坏碎片、受伤反馈和拾取物品。
- 手持火把、荧石提供局部照明；放置的发光方块使用自发光外观。

## 生存与创造

- 第一人称鼠标视角，行走、跳跃、疾跑、潜行、碰撞、重力、游泳与水下氧气。
- 潜行时限制走出方块边缘；跌落、溺水、饥饿、敌对生物与爆炸可以造成伤害。
- 生命、饥饿、经验、快捷栏、挖掘进度和可选调试信息。
- 持续挖掘、方块放置、物品掉落与拾取；矿物需要相应等级的镐，工具有耐久。
- 木、石、铁、钻石四组镐、斧、锹、剑。
- 食物补充饥饿；饥饿充足时逐渐恢复生命。
- 创造模式可以无限放置，双击空格切换飞行，使用分类与搜索选择方块及物品。
- 可在暂停菜单、F4 或命令中切换模式；当前实现不限制单人命令权限。
- 沙子、沙砾在触发更新后向下落到支撑面；TNT 支持倒计时和连锁爆炸。
- 死亡界面与重生；死亡会清空背包并在死亡位置产生掉落物。

## 背包、合成与容器

- 36 格背包，前 9 格为快捷栏；数量堆叠、拆分、交换、单个放置和快速转移。
- 背包 2 × 2 合成、工作台 3 × 3 合成，支持形状偏移与左右镜像。
- 配方书可检查所需材料，并自动将已有材料放入合成格；材料不足时不消耗背包物品。
- 木板、木棍、工作台、火把、熔炉、箱子、砖块、黏土块、面包、TNT、西瓜及四组工具的配方。
- 三槽熔炉具有燃料消耗、燃烧时间、烧炼进度与产物堆叠；可烧炼矿物、玻璃、石头、红砖和肉类等。
- 27 格箱子，可存放物品；破坏容器时释放其内容。
- 背包、箱子与熔炉状态均纳入世界存档。

## 生物与声音

- 绵羊、猪、牛拥有独立的方块模型、眼睛、腿部动画和游荡行为。
- 生成位置检查完整身体空间，移动时避开障碍、深落差和水面。
- 攻击有距离、命中遮挡和工具伤害；动物受伤后逃离，死亡掉落相应材料或食物。
- 夜间生成僵尸，僵尸追逐并攻击生存玩家；白天暴露在天空下会受伤，屋顶可遮蔽阳光。
- 生物类型、位置、生命与朝向可以随世界保存恢复。
- 步行、挖掘、放置、战斗、吃东西等声音由 Web Audio 合成，首次交互后启用。

## 中文界面与存档

- 标题画面、世界选择、创建世界、加载画面、暂停菜单、设置、操作指南、背包、工作台、熔炉、箱子、创造物品栏和死亡界面。
- 世界可设置中文名称、文字或数字种子、生存或创造模式。
- 可调整音量、鼠标灵敏度、视野、可视距离、视角晃动与调试显示。
- 多世界存档保存在当前浏览器的本地存储中，支持 JSON 导出和导入。
- 自动保存，并在暂停、退出等时机保存。更换浏览器、清除网站数据或进入不同站点地址不会共享这些存档，迁移请使用导出文件。
- 提供触摸方向键、跳跃/下潜、挖掘、放置、背包及暂停按钮；拖动场景调整视角。桌面键鼠是主要操作方式。

## 桌面操作

| 操作 | 按键或鼠标 |
| --- | --- |
| 移动 | W / A / S / D，或方向键 |
| 调整视角 | 移动鼠标 |
| 跳跃 / 游泳上浮 | 空格 |
| 疾跑 | Ctrl + 移动 |
| 潜行 / 飞行下降 | Shift |
| 挖掘 / 攻击 | 按住鼠标左键 |
| 放置 / 使用 / 打开容器 | 鼠标右键 |
| 创造模式取目标方块 | 鼠标中键 |
| 切换快捷栏 | 1–9 或滚轮 |
| 打开 / 关闭背包 | E |
| 关闭背包 / 暂停 | Esc |
| 吃手中食物 | 右键或 F |
| 丢出一个物品 | Q |
| 丢出当前一整叠 | Ctrl + Q |
| 创造模式切换飞行 | 快速双击空格 |
| 飞行上升 / 下降 | 空格 / Shift |
| 切换生存 / 创造 | F4 |
| 切换调试显示 | F3 |
| 打开本地聊天 / 命令输入 | T 或 / |

背包中：左键拿取或放置；右键拿取半叠或放置一个；Shift + 单击快速转移。合成结果支持 Shift + 单击连续制作，背包空间不足时停止。

浏览器会在进入游戏后锁定鼠标；若锁定被浏览器取消，点击“回到游戏”恢复。某些系统会拦截功能键，需要配合 Fn 使用。

内嵌浏览器拒绝或不实现鼠标锁定时，会自动采用兼容模式：Alt＋左键拖动视角，WASD 移动，左右键挖掘/放置。界面会保留兼容操作提示，拒绝锁定不会再次强制打开暂停菜单。

## 可用命令

这些命令只作用于当前单人世界，输入框不是多人聊天服务。

```text
/help
/gamemode creative
/gamemode survival
/give 橡木原木 16
/give 104 8
/time day
/time night
/time sunset
/time set 6000
/weather clear
/weather rain
/tp 8 50 8
/tp ~10 ~ ~-5
/seed
/save
/clear
```

物品接受项目内的数字 ID 或完整中文名称；ID 定义在 `src/data.js`。传送坐标支持 `~` 相对值。

## 与原版的明确差异

下列内容尚未实现，或使用了简化规则：

- 没有与 Java 版或基岩版逐版本对齐的兼容性承诺；原版存档、资源包、模组和服务器协议不能直接加载。
- 没有多人联网、账号体系、服务器、联机聊天与跨设备云存档。
- 没有下界、末地、传送门、末影龙、完整结构生成、村庄、交易和完整的生物列表。
- 没有红石电路、活塞、漏斗、矿车、船、自动化、完整方块状态与朝向系统。
- 没有完整农业、繁殖、钓鱼、附魔、药水、盔甲、副手、盾牌、成就和进度系统。
- 物品、配方、掉落、生物 AI、伤害、饱食、经验和挖掘参数是本项目的有限实现，不等同于原版全部规则。
- 水不是完整流体模拟；雨主要表现为天空与雨滴效果。没有完整光照传播、太阳阴影与原版天气系统。
- 方块与物品美术、声音、字体、菜单布局为独立实现，外观与原版存在差异。
- 白桦原木与橡木原木共用木板配方；烧炼木头使用煤炭物品表示产物；TNT 的点燃操作简化为右键使用。
- 游戏在菜单、聊天或容器界面会暂停大部分世界模拟；熔炉在容器界面继续处理。性能也会影响实际模拟速度。
- 本地存储容量受浏览器限制；大量编辑过的世界应定期导出备份。当前地图高度、渲染距离与生物数量均有上限。

## 验证范围

`npm test` 使用 Node 的测试运行器验证独立的游戏逻辑，包括地形与射线、背包与合成、熔炉、生物战斗及状态存取。`npm run build` 验证生产打包。

这些检查能够发现已覆盖规则的回归，不能证明与原版功能或画面完全一致，也不代表所有浏览器与移动设备均已经过实机验证。
